The MIT licence in [`LICENSE`](LICENSE) covers the code in `pipeline/`,
`scripts/` and `.opencode/`.

The datasets and the written studies use the Creative Commons Attribution 4.0
International licence (CC BY 4.0). This covers:

- `data/` — every CSV and JSON file, including the canonical dataset.
